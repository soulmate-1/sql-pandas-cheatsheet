SQL ↔ pandas 核心语法对照表

SQL 在左（更陌生，优先复习），pandas 在右（更熟练，用来类比记忆）

查数据 筛选 聚合 分组聚合 HAVING 排序 多表连接 窗口函数 日期处理 导出 排错

1 查数据

SQL
pandas
SELECT * FROM orders
直接查看整张表：df
SELECT city, sales FROM orders
df[["city","sales"]]
SELECT sales AS "销售额" FROM orders
df.rename(columns={"sales":"销售额"})
SELECT * FROM orders LIMIT 10
df.head(10)

2 筛选（WHERE）

SQL
pandas
WHERE category='Furniture'
df[df["Category"]=="Furniture"]
WHERE discount>0.2 AND profit<0
df[(df["Discount"]>0.2) & (df["Profit"]<0)]
WHERE city IN ('A','B','C')
df[df["City"].isin(["A","B","C"])]
WHERE profit IS NOT NULL
df[df["Profit"].notna()]

3 聚合函数

SQL
pandas
COUNT(*)
len(df) 或 df.shape[0]
SUM(sales)
df["Sales"].sum()
AVG(sales)
df["Sales"].mean()
MAX(sales) / MIN(sales)
df["Sales"].max() / .min()
COUNT(DISTINCT city)
df["City"].nunique()

4 分组聚合（GROUP BY）

SQL
pandas
SELECT cat, SUM(sales) FROM orders GROUP BY cat
df.groupby("Category")["Sales"].sum()
SELECT cat, SUM(sales), SUM(profit) FROM orders GROUP BY cat
df.groupby("Category")[["Sales","Profit"]].sum()
SELECT cat, SUM(sales), AVG(dis) FROM orders GROUP BY cat
df.groupby("Category").agg({ "Sales":"sum", "Discount":"mean" })

5 分组后过滤（HAVING）

SQL
pandas
GROUP BY cat HAVING SUM(profit) < 0
先 groupby，再布尔筛选：
m = df.groupby("Category")["Profit"].sum()
m[m < 0]
WHERE vs HAVING：WHERE 分组前过滤（原始行），HAVING 分组后过滤（聚合结果）

6 排序（ORDER BY）

SQL
pandas
ORDER BY profit DESC
df.sort_values("Profit", ascending=False)
ORDER BY sales ASC, profit DESC
df.sort_values(["Sales","Profit"], ascending=[True,False])

7 多表连接（JOIN）

SQL
pandas
a JOIN b ON a.city=b.city
pd.merge(a,b,on="City",how="inner")
或 a.merge(b,on="City",how="inner")
a LEFT JOIN b ON a.city=b.city
pd.merge(a,b,on="City",how="left")
a JOIN b ON a.cid=b.id
pd.merge(a,b,left_on="cid",right_on="id")

8 窗口函数

SQL
pandas
ROW_NUMBER() OVER( PARTITION BY cat ORDER BY sales DESC)
无直接等价，用 groupby+rank 模拟
RANK() / DENSE_RANK() OVER(...)
df.groupby("cat")["sales"].rank(method="dense")
LAG(sales,1) OVER(ORDER BY 日期)
df["Sales"].shift(1)
LEAD(sales,1) OVER(ORDER BY 日期)
df["Sales"].shift(-1)
SUM(sales) OVER( PARTITION BY cat)
df.groupby("Category")["Sales"].transform("sum")
GROUP BY vs PARTITION BY：GROUP BY 压缩行数（聚合，丢细节），PARTITION BY 不压缩行数（只在行旁贴标签，如排名）

df["日期"].dt.month

! SQL 排错三板斧

  1. 英文拼写：PARTITION 不是 PARTION，ASC 不是 ASCE，DESC 不是 DESK
  2. 中文符号混入：" vs "、， vs ,、） vs ) ——肉眼几乎看不出区别，但会直接报错
  3. 关键关键字漏掉：OVER、FROM、逗号位置
